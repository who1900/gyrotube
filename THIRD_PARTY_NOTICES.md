## hls.js

The web player can load [hls.js](https://github.com/video-dev/hls.js) (Apache-2.0) at runtime from jsDelivr when an HLS URL is opened. It is not vendored in this repository.

## Big Buck Bunny test stream

The "Демо-стрим HLS" button opens a public Mux test stream of *Big Buck Bunny*. That film is not included in this repository.
